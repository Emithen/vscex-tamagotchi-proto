# 픽셀 에셋 원본

기본 펫 `물짱이`의 런타임 스프라이트(`mudkip-*`)는 포켓몬 블랙·화이트(Gen5) 배틀 스프라이트에서 파생했습니다.

- `mudkip-front-gen5.png`: 정적 정면 스프라이트 (96×96 캔버스, 14색). 팔레트 기준 원본입니다.
- `mudkip-front-gen5.gif`: 정면 배틀 애니메이션 (43×49, 82프레임, 고유 프레임 57개). 포즈 원본입니다.

두 파일 모두 런타임에서 직접 사용하지 않습니다.

## 변환 규칙

- 프레임: 48×48px. GIF 프레임을 가로 2px 여백으로 배치하고, 바닥선이 프레임 맨 아래 행에 오도록 1px 올립니다. 점프 프레임은 위쪽이 잘리지 않게 그만큼 다시 내립니다.
- 방향: 원본은 왼쪽을 보므로 좌우 반전해 오른쪽을 보게 합니다. 전투의 적은 CSS `--sprite-facing`으로 다시 뒤집습니다.
- 팔레트: GIF 색은 PNG 색과 RGB 값이 1씩 다르므로 `../palettes/mudkip.json`의 PNG 14색 중 가장 가까운 색으로 매핑합니다.
- 알파: 128 미만은 완전 투명, 이상은 완전 불투명으로 바꿉니다.

## 애니메이션별 원본 프레임

번호는 GIF의 고유 프레임 순번(0부터)입니다. `dx`는 바라보는 방향 기준 이동 픽셀입니다.

| 애니메이션 | 시트 칸에 쓴 원본 프레임                         | 비고                         |
| ---------- | ------------------------------------------------ | ---------------------------- |
| idle       | 0, 1, 2                                          | 호흡                         |
| blink      | 0, 0(눈 반쯤 감음), 0(눈 감음)                   | 눈 픽셀을 수동 편집          |
| eat        | 4, 8, 0                                          | 입 벌림과 착지 반복          |
| happy      | 0, 4, 5, 8                                       | 깡충 뛰기                    |
| hungry     | 36, 38, 40, 42                                   | 낮게 웅크린 흔들림           |
| attack     | 0, 4(`dx` +1), 5(`dx` +3), 8                     | 앞으로 뛰어듦                 |
| hit        | 0(흰색 실루엣), 8(`dx` -2), 13(`dx` -1), 0        | 피격 섬광 후 뒤로 밀림       |
| faint      | 37을 아래로 0, 5, 14, 26px 이동                  | 프레임 밖으로 가라앉음       |
| victory    | 0, 5, 11                                         | 입 벌린 점프                 |

변환 스크립트는 저장소에 두지 않았습니다. 다시 만들거나 프레임을 바꿀 때는 Sprite Studio로 직접 편집하거나 위 규칙대로 다시 변환하세요.
