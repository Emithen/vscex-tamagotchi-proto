# 프로젝트 문서

이 디렉터리는 Tamagotchi 확장 프로그램의 진행 상황, 구조, 개발 방법을 정리합니다.

## 권장 읽기 순서

1. [로드맵](roadmap.md): 현재 완료된 기능과 다음 작업 후보를 먼저 확인합니다.
2. [아키텍처](architecture.md): 작업에 필요한 주요 구성 요소와 데이터 흐름을 파악합니다.
3. [전투 밸런싱](balance.md): 전투 계산식과 기준 스탯, 조정 원칙을 확인합니다.
4. [Pixel Perfect 시스템](pixel-perfect.md): 픽셀 아트와 Webview 렌더링 규격, 단계별 구축 계획을 확인합니다.
5. [개발 가이드](development.md): 설치, 실행, 검사, 테스트 방법을 확인합니다.

## 문서 관리 원칙

- 루트 `README.md`에는 프로젝트 소개와 빠른 시작 방법을 둡니다.
- 이 디렉터리에는 개발과 유지보수에 필요한 상세 내용을 둡니다.
- 실제 구현과 계획을 구분하여 기록합니다.
- 구조나 사용 방법이 바뀌면 관련 코드와 문서를 함께 갱신합니다.
- 문서가 길어질 때만 하위 디렉터리로 분리합니다.

버전별 변경 사항은 루트의 `CHANGELOG.md`, 저장소 작업 규칙은 `AGENTS.md`에서 관리합니다.
